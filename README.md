# 중급 한국어 단어장 🇰🇷

국립국어원 **한국어기초사전의 등급별 어휘(중급)** 분류를 기준으로 선별한 한국어 단어를,
**예문과 함께 한국어로 낭독**해 주고 **영어로 뜻과 문장을 설명**해 주는 웹 학습 앱입니다.

- 설치·서버·API 키 없이 브라우저만 있으면 동작합니다 (순수 HTML/CSS/JS).
- 한국어·영어 낭독은 브라우저에 내장된 음성 합성(Web Speech API)을 사용합니다.
- 학습 진도(외운 단어·즐겨찾기)와 설정은 브라우저(localStorage)에 저장됩니다.
- **앱 UI는 영어**입니다(영어권 학습자 대상). 한국어는 단어·발음·예문·한국어 뜻풀이 등 학습 콘텐츠에만 표시됩니다.

## 시작하기

가장 간단한 방법 — `index.html`을 브라우저로 열면 끝입니다.

로컬 서버로 여는 것을 권장합니다(폰트·아이콘 로딩이 더 안정적):

```bash
# 둘 중 편한 것 하나로
python3 -m http.server 8000
npx serve .
```

그다음 브라우저에서 `http://localhost:8000` 접속.

> **권장 브라우저**: Chrome, Edge, Safari (한국어 TTS 품질이 좋습니다)

## 주요 기능

| 화면 | 설명 |
|---|---|
| **Study(학습)** | 플래시카드. 앞면엔 단어·표준 발음·품사, 카드를 누르면 영어 뜻·영어 해설·한국어 뜻풀이·예문(+영어 번역)이 나타납니다. 🔊 버튼으로 단어/예문을 한국어로 낭독, **Auto play**는 단어 → 영어 해설 → 예문(한→영) 순서로 읽어 줍니다. 연속 재생을 켜면 손대지 않아도 다음 카드로 넘어갑니다. |
| **Words(목록)** | 전체 단어 검색(한국어/영어)·주제별 필터. 행을 누르면 해당 단어 카드로 이동합니다. |
| **Quiz(퀴즈)** | Korean→English, English→Korean, **Listening**(발음 듣고 뜻 고르기) 3가지 유형, 10문제. 답을 고르면 정답 발음을 들려줍니다. |
| **Settings(설정)** | 낭독 속도(0.6×~1.4×), 한국어/영어 음성 선택, 자동 낭독·연속 재생·한국어 뜻풀이 표시 여부, 주제별 진행률, 진도 초기화. |

**키보드 단축키** — <kbd>←</kbd><kbd>→</kbd> 카드 이동 · <kbd>Space</kbd> 뜻 보기 · <kbd>P</kbd> 단어 낭독 · <kbd>A</kbd> 자동 읽기 · <kbd>F</kbd> 즐겨찾기 · <kbd>L</kbd> 외웠어요

## 수록 어휘

- `data/words.js` + `data/words2.js` 에 **주제 12개(감정·성격, 인간관계, 일상생활, 직장·업무, 학업·교육, 건강·생활, 여행·교통, 사회·문화, 경제·소비, 자연·환경, 부사·표현, 동사·형용사)** 로 나눈 중급 어휘 **360여 개**가 들어 있습니다.
- 각 단어는 **표준 발음(표기와 다른 경우), 품사, 영어 뜻, 영어 해설, 한국어 뜻풀이, 예문 2개(+영어 번역)** 를 갖추고 있습니다.
- 어휘 선정은 국립국어원 한국어기초사전의 등급별 어휘(중급) 분류를 기준으로 했고, 뜻풀이·예문·번역 텍스트는 본 프로젝트에서 학습용으로 새로 작성했습니다.

### 단어 직접 추가하기

`data/words.js` 형식 그대로 항목을 추가하면 됩니다:

```js
{w:"관습", p:"관습", pos:"명사", cat:"사회·문화",
 en:"custom; convention",
 def:"A way of behaving that a society has followed for a long time.",
 ko:"한 사회에서 오랫동안 지켜 내려온 질서나 풍습.",
 ex:[["오래된 관습을 하루아침에 바꾸기는 어렵다.","It is hard to change an old custom overnight."]]}
```

### 오픈 API로 단어 가져오기 (선택)

국립국어원 한국어기초사전 [오픈 API](https://krdict.korean.go.kr/openApi/openApiInfo) 키(무료 발급)가 있으면
스크립트로 단어를 추가할 수 있습니다:

```bash
# 키 발급: https://krdict.korean.go.kr/openApi/openApiRegister  (Node.js 18+ 필요)
KRDICT_API_KEY=발급받은키 node scripts/fetch-krdict.mjs 관습 성취 극복하다
KRDICT_API_KEY=발급받은키 node scripts/fetch-krdict.mjs --file 단어목록.txt
```

- 결과는 `data/words.extra.js` 에 저장되고 앱이 자동으로 함께 읽습니다.
- API는 **예문의 영어 번역을 제공하지 않으므로** 예문 번역 칸은 비어 있게 저장됩니다(직접 채워 넣을 수 있어요).

  출처(국립국어원 한국어기초사전)를 밝히고 동일조건변경허락 조건을 지켜 주세요.

## 낭독(TTS) 안내

- 낭독은 OS/브라우저에 설치된 음성을 사용합니다. **설정 → 낭독**에서 음성을 고를 수 있어요.
  - Windows: 설정 → 시간 및 언어 → 음성에서 한국어 음성 추가
  - macOS/iOS: 설정 → 손쉬운 사용 → 콘텐츠 말하기(유나 등 한국어 음성)
  - Android(Chrome): Google TTS 한국어 음성 기본 제공
- 한국어 음성이 하나도 없으면 낭독 버튼이 소리를 내지 않을 수 있습니다. 위 방법으로 음성을 설치해 주세요.

## 프로젝트 구조

```
├── index.html              # 단일 페이지 앱
├── css/style.css           # 스타일 (라이트/다크 자동)
├── js/app.js               # 학습·목록·퀴즈·설정 + TTS 로직
├── data/words.js           # 내장 중급 어휘 데이터 (1차)
├── data/words2.js          # 내장 중급 어휘 데이터 (2차 확장)
├── data/words.extra.js     # 오픈 API로 추가한 단어 (스크립트가 생성)
├── scripts/fetch-krdict.mjs# 오픈 API 단어 가져오기 스크립트
├── sw.js                   # 오프라인 지원 서비스 워커
├── assets/icon.svg         # 앱 아이콘
└── manifest.webmanifest    # 홈 화면 추가용 매니페스트
```

> **오프라인 사용**: https 또는 localhost로 한 번 열면 서비스 워커가 앱 전체를 캐시해,
> 이후에는 인터넷 없이도 동작합니다(브라우저 TTS도 기기 내장 음성이면 오프라인으로 작동).
